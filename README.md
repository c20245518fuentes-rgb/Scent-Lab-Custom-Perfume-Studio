
# Scent Lab — Custom Perfume Studio

Scent Lab is a custom perfume studio website concept designed to help
fragrance lovers explore scent families and learn about personalized
fragrance experiences.

## Project Overview

The website introduces the Scent Lab brand, showcases fragrance inspirations,
explains the customization process, shares the brand story, and provides a
contact form for inquiries.

This first version focuses on the website's HTML structure, content, and
initial visual design.

## Features in Commit 1

- Semantic HTML page structure
- Header and navigation links
- Hero section with calls to action
- Four fragrance family cards
- Custom fragrance introduction
- Three signature fragrance cards
- Three-step process section
- Brand story section
- Contact form with name, email, and message fields
- Footer with automatically updated copyright year
- Initial responsive layouts using Tailwind CSS
- Custom typography using Google Fonts

## Technologies Used

- HTML5
- Tailwind CSS v4 browser CDN
- JavaScript
- Google Fonts

## Design System

### Color Palette

| Color | Hex Code | Purpose |
|---|---|---|
| Cream | `#F5F0E8` | Main page background |
| Ink | `#29251F` | Text and dark sections |
| Gold | `#B58A5A` | Accent color |
| Sand | `#E7DED1` | Cards and supporting backgrounds |
| Muted | `#71695F` | Secondary text |

### Typography

- **Playfair Display:** Headings and decorative text
- **DM Sans:** Body text and interface elements

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Make sure you have an internet connection for the Tailwind CSS CDN
   and Google Fonts.

## Contact Form Notice

The contact form is currently a front-end demonstration. It does not send
or store submitted information on a server.
